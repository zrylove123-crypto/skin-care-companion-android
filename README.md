# 智群健康搭子 Android

刘智群的私人护肤、减脂、训练、健康记录、提醒和 AI 沟通应用。

## 已内置

- 四阶段护肤流程，按开始日期自动计算当天任务
- 剃须当天自动跳过水杨酸
- 出油、干燥、刺激每日打卡
- 体重、腰围、血压、步数、睡眠、训练与饥饿记录
- 目标进度、7天趋势、个性化外食和训练方案
- 高血压训练保护与异常血压提示
- 安卓本地早晚通知，软件关闭后仍可提醒
- 文字、皮肤照片和餐食照片聊天
- AI 接口密钥仅保存在手机应用私有空间
- 核心流程、记录与提醒不依赖网页，断网也能使用

## 安装

在仓库 Releases 下载 `skin-care-companion.apk`，允许浏览器“安装未知应用”后安装。

AI 聊天默认使用国内可访问的阿里云百炼兼容接口和通义千问视觉模型 qwen3-vl-plus。安装后只需在“设置”中创建并粘贴自己的 API 密钥；接口地址和模型名已预填，也可切换至 OpenAI Responses。不要把密钥写进源码、聊天或提交到仓库。
