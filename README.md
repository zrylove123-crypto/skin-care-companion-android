# 护肤搭子 Android

刘智群的私人护肤计划、打卡、提醒和 AI 沟通应用。

## 已内置

- 四阶段护肤流程，按开始日期自动计算当天任务
- 剃须当天自动跳过水杨酸
- 出油、干燥、刺激每日打卡
- 安卓本地早晚通知，软件关闭后仍可提醒
- 文字和皮肤照片聊天
- AI 接口密钥仅保存在手机应用私有空间
- 核心流程、记录与提醒不依赖网页，断网也能使用

## 安装

在仓库 Releases 下载 `skin-care-companion.apk`，允许浏览器“安装未知应用”后安装。

AI 聊天需要在“设置”中填写 HTTPS 接口、模型名和 API 密钥。可使用 OpenAI Responses 接口，或选择国内/兼容接口。不要把密钥写进源码或提交到仓库。
